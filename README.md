# Research Report 1

**On-Policy Self-Distillation with Privileged Information**  
Mathematical Reasoning in Language Models under 30B Parameters

This literature survey examines ten 2026 preprints on privileged-information self-distillation for mathematical reasoning. It compares revision-based training, contrastive supervision, and reward calibration, with attention to experimental controls and compute costs.
